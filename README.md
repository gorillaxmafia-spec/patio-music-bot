# PATIO MUSIC — Now Playing Button Edition

The player message is styled like the reference:
- Now Playing card
- Song title + duration
- Thumbnail
- Pause
- Skip
- Shuffle
- Stop
- Like

Use `/panel` to send the controls again.

## Setup
1. Upload this project to GitHub.
2. Deploy the repository on Railway.
3. Add:
   - `DISCORD_TOKEN`
   - `CLIENT_ID`
   - `GUILD_ID`
4. Deploy with `npm start`.

## Discord permissions
View Channel, Connect, Speak.

Do not upload `.env` or your bot token.

## Other commands
`/play`, `/pause`, `/resume`, `/skip`, `/stop`, `/queue`, `/nowplaying`, `/volume`, `/loop`, `/join`, `/ping`, `/help`, `/panel`.
